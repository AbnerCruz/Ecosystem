## Implicação para C# total

FATO EXTERNO: .NET no navegador usa infraestrutura de carregamento/interoperabilidade com JavaScript; APIs do navegador como armazenamento/picker não se tornam System.IO por mudar de linguagem [S1]. Blazor PWA utiliza service worker [S2]. Blazor Hybrid executa componentes .NET em hosts com WebView [S3]. Avalonia inclui Windows, Android e browser/WASM, com suporte por plataforma [S4].

INFERÊNCIA: reescrever domínio, regras, editor e mundo em C# é diferente de garantir zero bytes JavaScript entregues pelo framework. Não rotular KaTeX/PDF.js/plugins existentes como C# total. Se UC-5 precisar de exceção técnica, apresentar exatamente seu escopo ao proprietário; a implementação não presume consentimento.

RECOMENDAÇÃO PARA A INVESTIGAÇÃO, não decisão: comparar uma UI C# de controles/desenho (mesma base Windows/Android/browser) com uma UI C# sobre DOM (WebAssembly + hosts nativos). Provar editor móvel, mundo e migração local antes de selecionar. MAUI sozinho não fecha a superfície browser; a alternativa exige cliente Web separado/compartilhado. Nenhum benchmark ou compatibilidade de biblioteca foi fabricado.
