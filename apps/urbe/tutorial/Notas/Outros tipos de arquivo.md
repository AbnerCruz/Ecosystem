# Outros tipos de arquivo

O Urbe é feito para notas em Markdown, mas também guarda e mostra outros arquivos.

## Arquivos de texto (editáveis)

| Tipo | Para que serve | No editor |
|---|---|---|
| `.md`, `.markdown` | Notas | Visual e Fonte |
| `.txt` | Texto simples | Fonte |
| `.html`, `.htm` | Páginas da web | Prévia e código |
| `.page.json` | Páginas do Urbe | Abre no Estúdio (veja [[Tutorial/Páginas/O que são páginas|O que são páginas]]) |
| `.js`, `.mjs` | Código JavaScript (e plugins) | Código |
| `.css` | Estilos (e estilos do Urbe) | Código |
| `.json`, `.yaml`, `.yml` | Dados e configurações | Código |
| `.csv` | Tabelas | Código |

Cada tipo vira uma construção diferente na cidade (veja [[Tutorial/Cidade/Como a cidade funciona|Como a cidade funciona]]).

## Imagens e outros arquivos

Imagens, PDFs e outros arquivos que você importa ficam guardados e aparecem na cidade como **armazéns**. Toque para **Visualizar**, **Renomear**, **Mover** ou **Excluir**.

Para mostrar uma imagem dentro de uma nota, use `![descrição](caminho/da/imagem.png)`.

## Arquivos especiais do Urbe

- A pasta **Personalização** guarda a aparência, os estilos, as texturas e os plugins. Veja [[Tutorial/Personalização/Visão geral da personalização|Visão geral da personalização]].
- Arquivos dentro de pastas que começam com ponto (como `.urbe`) são internos: guardam o mapa da cidade, a lixeira e o histórico. Não aparecem nas notas.
