# Tags e propriedades

## Tags

Tags são etiquetas para marcar assuntos que atravessam várias pastas. Escreva `#` seguido de uma palavra, sem espaço, em qualquer lugar do texto. Por exemplo, escrever `#receita` numa nota marca essa nota como receita.

- Use hífen ou barra em tags compostas: `#livro-lido`, `#projeto/casa`.
- O Assistente sabe achar notas por tag ("liste as notas com a tag receita").
- Plugins podem usar tags. Por exemplo, o modelo de plugin **Desenho no mapa** põe uma estrela nas casas com a tag `#importante`.

## Propriedades

No começo de uma nota você pode colocar um bloco de **propriedades**, entre duas linhas de `---`:

```
---
autor: Ana
status: rascunho
tags: [ideia, casa]
---
```

No modo Visual, as propriedades aparecem num cartão no topo da nota. As tags escritas nas propriedades valem como tags normais.
