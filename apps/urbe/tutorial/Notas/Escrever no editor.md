# Escrever no editor

Quando você abre uma nota, ela aparece no **editor**, em tela cheia.

## Visual e Fonte

No topo há duas opções:

- **Visual**: você vê o texto já formatado (títulos grandes, **negrito**, listas, tabelas) e escreve direto nele, como num processador de texto.
- **Fonte**: você vê o texto puro, em **Markdown**, com os símbolos que fazem a formatação. Veja [[Tutorial/Notas/Markdown sem medo|Markdown sem medo]].

As duas mostram a mesma nota e dá para trocar a qualquer momento. Em **Personalização → Editor** você escolhe com qual delas as notas abrem.

## A barra de ferramentas

Logo abaixo do topo:

| Botão | Faz |
|---|---|
| H1, H2, H3 | Títulos (grande, médio e pequeno) |
| **B** | Negrito |
| *I* | Itálico |
| `<>` | Código |
| Lista | Lista com marcadores |
| ☑ | Lista de tarefas (com caixinha para marcar) |
| ❝ | Citação |
| Vincular nota | Link para outra nota (vira uma rua) |
| 🔗 | Link para um site |
| — | Linha separadora |
| ∑ | Fórmula matemática (veja [[Tutorial/Matemática/Fórmulas em qualquer nota|Fórmulas em qualquer nota]]) |

## Atalhos que aparecem sozinhos

- **Selecione um trecho** no modo Visual e uma bolha aparece com negrito, itálico, código, link de nota, link externo, título e citação.
- Numa **linha vazia**, digite `/` para escolher o tipo do bloco: título, lista, tarefa, citação, divisória ou link.
- Digite `[[` para ver a lista de notas e ligar uma delas.

## Salvar

Tudo é salvo sozinho. O rodapé mostra **Salvo** quando está tudo guardado. Também dá para apertar **Ctrl+S** (**⌘S**) se quiser ter certeza.

## O menu ⋯

No canto de cima:

- **Renomear** a nota.
- **Assistente**: pede ajuda à IA sobre esta nota.
- **Mostrar nas notas**: mostra onde a nota está na aba Notas.
- **Versões anteriores**: volta a nota para como ela estava antes (veja [[Tutorial/Notas/Lixeira, versões e desfazer|Lixeira, versões e desfazer]]).
- **Estrutura e backlinks**: os títulos da nota e as notas que apontam para ela (veja [[Tutorial/Notas/Abas, painel dividido e navegação|Abas, painel dividido e navegação]]).
- **Mover para a lixeira**.

O botão **Assistente**, no rodapé, abre a IA com esta nota como contexto.
