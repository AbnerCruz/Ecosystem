# Links entre notas

Ligar notas é o coração do Urbe. Quando uma nota menciona outra, aparece uma **rua** entre as duas casas, e os moradores começam a andar por ela.

## Como fazer

Escreva o nome da outra nota entre colchetes duplos:

`[[Nome da nota]]`

Outros jeitos:

- Digite `[[` e escolha a nota na lista que aparece.
- Use o botão **Vincular nota** da barra de ferramentas.
- Selecione uma palavra e toque em **Transformar em link de nota**, na bolha.

## Mostrar outro texto no link

Use uma barra `|` para mostrar um texto diferente do nome:

`[[Nome da nota|clique aqui]]`

É assim que este Tutorial funciona. Por exemplo, [[Tutorial/Comece aqui|este link]] leva para "Comece aqui".

## Notas com o mesmo nome

Se duas notas têm o mesmo nome em pastas diferentes, escreva o caminho completo: `[[Pasta/Nome da nota]]`.

## Abrir um link

Toque no link (no modo Visual). Se a nota não existir, o Urbe avisa.

## Quem aponta para esta nota?

No menu ⋯ do editor, **Estrutura e backlinks** mostra as notas que têm link para a nota aberta. São os **backlinks**. Ajudam a descobrir conexões que você nem lembrava.

> [!tip] Experimente
> Crie duas notas, escreva o nome de uma dentro da outra usando `[[ ]]` e volte para a Cidade: a rua aparece na hora.
