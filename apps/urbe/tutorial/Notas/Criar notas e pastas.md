# Criar notas e pastas

## Sua primeira nota

1. Toque no botão **＋** (canto de baixo da Cidade).
2. Escolha **Nova nota**.
3. Dê um nome, por exemplo `Ideias`. Não precisa escrever `.md`: o Urbe completa sozinho.
4. A nota abre no editor. Escreva o que quiser. **Não existe botão de salvar**: tudo é guardado sozinho enquanto você escreve.

Quando você voltar para a Cidade, vai ver uma casa nova com o nome da nota.

## Outros caminhos para criar

- Na aba **Notas**, o botão **Nova** no topo cria uma nota dentro da pasta que está aberta.
- No computador, o atalho **Ctrl+N** (ou **⌘N** no Mac) cria uma nota.
- Com **＋ → Adicionar construção**, você escolhe no mapa onde a casa vai ficar.
- O Assistente também cria notas quando você pede (veja [[Tutorial/Assistente/Conhecendo o Assistente|Conhecendo o Assistente]]).

## Pastas

Pastas organizam as notas por assunto, e cada uma vira um bairro na cidade.

- **＋ → Nova pasta**, ou na aba Notas, menu ⋯ → nova pasta.
- Pastas podem ficar dentro de outras pastas.
- Para colocar uma nota numa pasta, crie a nota com a pasta aberta ou use **Mover** (veja [[Tutorial/Notas/A aba Notas|A aba Notas]]).

## Nomes

- Evite os caracteres `/ \ : * ? " < > |`: eles não podem ser usados em nomes de arquivo.
- Dois arquivos na mesma pasta não podem ter o mesmo nome.
- Para renomear, toque no **nome da nota** no topo do editor, ou use o menu ⋯ → **Renomear**.
