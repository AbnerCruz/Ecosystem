# A aba Notas

A segunda aba, **Notas**, mostra todos os seus arquivos em forma de lista, como as pastas de um computador. É o jeito mais rápido de achar e organizar as coisas.

## O que tem na tela

- **Buscar notas**: o campo no topo filtra pelo nome enquanto você digita.
- **Pastas**: toque para abrir. O caminho aparece no topo, e a seta volta.
- **Notas**: toque para abrir no editor.
- **Nova**: cria uma **nota**, uma **pasta** ou uma **página** na pasta aberta.
- **⋯ (mais opções)**:
  - **Recentes**: as últimas notas que você abriu.
  - **Favoritos**: as notas que você marcou com estrela.
  - **Páginas**: seus sites e páginas (veja [[Tutorial/Páginas/O que são páginas|O que são páginas]]).
  - **Composições**: documentos montados com várias notas (veja [[Tutorial/Páginas/Composições|Composições]]).
  - **Importar arquivos** e **Exportar tudo (.zip)** (veja [[Tutorial/Arquivos e segurança/Importar e exportar|Importar e exportar]]).
  - **Lixeira** (veja [[Tutorial/Notas/Lixeira, versões e desfazer|Lixeira, versões e desfazer]]).
  - **Pasta do Urbe no dispositivo** (veja [[Tutorial/Arquivos e segurança/Onde ficam seus arquivos|Onde ficam seus arquivos]]).

## Selecionar várias notas

**Toque e segure** uma nota (ou pasta) para selecionar. Depois é só tocar em outras para somar à seleção. Uma barra aparece embaixo com:

| Botão | O que faz |
|---|---|
| Abrir | Abre a nota selecionada |
| Mover para pasta | Leva tudo para outra pasta |
| Duplicar | Faz cópias |
| Favoritar | Marca com estrela |
| Compor documento | Junta as notas num documento só |
| Mover para a lixeira | Apaga (dá para recuperar) |
| Limpar seleção | Desmarca tudo |

No computador, clique com **Ctrl** (ou **⌘**) apertado para selecionar várias.
