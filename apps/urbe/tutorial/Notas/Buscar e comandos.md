# Buscar e comandos

## Buscar notas

Toque na 🔍 **lupa** no topo da Cidade, ou aperte **Ctrl+P** (**⌘P** no Mac).

- Procura pelo **nome** e pelo **conteúdo** das notas.
- Não liga para acentos nem para maiúsculas: `acao` acha "Ação".
- Use as setas **↑ ↓** e **Enter** para abrir, ou toque no resultado.

Na aba **Notas**, o campo **Buscar notas** filtra a lista pelo nome.

## Localizar e substituir dentro da nota

Com uma nota aberta, aperte **Ctrl+F** (**⌘F**). Aparece uma barra com:

- **Localizar**: o texto que você procura (mostra quantos resultados existem).
- **Próximo**: pula para o próximo resultado.
- **Substituir** e **Todos**: trocam um resultado ou todos de uma vez.

Essa busca trabalha no texto puro, então o editor passa para o modo **Fonte** enquanto ela está aberta.

## A paleta de comandos

Aperte **Ctrl+K** (**⌘K**) para abrir a **paleta de comandos**: uma lista com tudo o que o Urbe sabe fazer. Digite parte do nome e aperte Enter.

Alguns comandos úteis:

| Comando | O que faz |
|---|---|
| Nova nota / Nova pasta | Cria |
| Buscar notas | O mesmo que Ctrl+P |
| Enquadrar todas as notas | Mostra a cidade inteira |
| Abrir cidade / Abrir notas / Abrir IA | Troca de tela |
| Localizar e substituir | O mesmo que Ctrl+F |
| Abrir em painel dividido | Mostra outra nota ao lado |
| Outline e backlinks | Estrutura da nota e quem aponta para ela |
| Voltar / Avançar | Navega entre notas abertas |
| Inserir fórmula | Abre o editor de fórmulas |
| Páginas / Nova página | Estúdio de páginas |
| Personalização / Plugins | Abre a personalização |
| Abrir tema.json | Edita a aparência como texto |
| Restaurar aparência padrão | Desfaz a personalização |
| Recarregar plugins | Reinicia os plugins ligados |
| Diagnóstico do workspace | Confere se está tudo bem com os arquivos |
| Tutorial / Restaurar o Tutorial | Abre ou recria esta pasta |
| Configurações | Abre as configurações |

Plugins podem adicionar comandos novos a essa lista (veja [[Tutorial/Personalização/Plugins|Plugins]]).
