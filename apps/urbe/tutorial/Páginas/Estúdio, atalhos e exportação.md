# Estúdio, atalhos e exportação

## Publicar a página

No menu **Exportar** do estúdio:

- **Imprimir ou salvar PDF**: abre a impressão do navegador; escolha **Salvar como PDF** para gerar o arquivo. Num livro, saem o tamanho de página, as margens e os números do livro (veja [[Tutorial/Páginas/Livros|Livros]]).
- **Baixar HTML**: um arquivo único, com tudo dentro, que funciona em qualquer hospedagem (GitHub Pages, Netlify, o servidor da sua escola…) ou até aberto direto no computador.
- **Copiar HTML**: copia o código para colar em outro lugar.
- **Salvar HTML no vault**: cria um arquivo `.html` ao lado da página, dentro do Urbe.
- **Abrir em nova aba**: vê a página como um visitante veria.

## Outras ações

- **Editar JSON**: o texto completo da página, para quem gosta de ajustar à mão. O Urbe confere tudo antes de aplicar e mostra os erros.
- **Duplicar página**, **Salvar como modelo** e **Mover página para a lixeira**.
- Em cada seção: **Editar**, **Mover para cima/baixo**, **Duplicar**, **Trocar tipo de bloco…** e **Remover**.

## Atalhos no computador

| Atalho | Faz |
|---|---|
| `/` ou `A` | Adicionar bloco |
| `↑` `↓` ou `J` `K` | Selecionar seção |
| Enter | Editar a seção selecionada |
| Alt+↑ / Alt+↓ | Mover a seção |
| Ctrl+D | Duplicar a seção |
| Delete | Remover a seção |
| Ctrl+Z / Ctrl+Shift+Z | Desfazer / refazer |
| Ctrl+S | Salvar agora |
| Ctrl+J | Editar JSON |
| Ctrl+E | Exportar |
| Ctrl+P | Abrir em nova aba |
| 1, 2, 3 | Prévia de celular, tablet ou computador |
| T | Tema |
| Esc | Sair do campo, fechar ou voltar |

No Mac, troque **Ctrl** por **⌘**. A lista também aparece no menu, em **Atalhos de teclado**.
