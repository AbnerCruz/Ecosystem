# Composições

Uma **composição** junta várias notas num **documento só**, com aparência caprichada, pronto para imprimir, salvar como PDF ou mandar para alguém. É ótima para trabalhos, apostilas e relatórios.

## Criar

1. Na aba **Notas**, **toque e segure** a primeira nota e depois toque nas outras.
2. Na barra de baixo, toque em **Compor documento**.

A composição abre com uma prévia de todas as notas em sequência.

## Ajustar

- **Fontes**: a lista das notas. Use ↑ ↓ para mudar a ordem.
- **Documento**: fonte, tamanho, entrelinha, cor, fundo e alinhamento do documento todo.
- **Toque num trecho** da prévia para mudar só aquele elemento (por exemplo, só um título).
- **CSS**: regras de estilo próprias.
- **HTML**: edite o código completo do documento. **Voltar ao gerado** desfaz essas mudanças.
- **✎** renomeia a composição.

## Levar para fora

**Exportar** baixa um arquivo `.html`. Abra no navegador e use **Imprimir → Salvar como PDF** se precisar de PDF.

Suas composições ficam guardadas e aparecem em **Notas → ⋯ → Composições**.

> [!tip] Composição ou página?
> Composição é um **documento** para ler ou imprimir. Página é um **site**, com seções, botões e navegação. Veja [[Tutorial/Páginas/O que são páginas|O que são páginas]].
