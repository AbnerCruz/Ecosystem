# Atalhos de teclado

No Mac, troque **Ctrl** por **⌘ (Command)**.

## Gerais

| Atalho | Faz |
|---|---|
| Ctrl+K | Paleta de comandos |
| Ctrl+P | Buscar notas |
| Ctrl+N | Nova nota |
| Ctrl+S | Salvar agora (o Urbe já salva sozinho) |
| Ctrl+Shift+M | Ir para a Cidade |
| Ctrl+Shift+F | Abrir a aba Notas |
| Esc | Fecha menus, diálogos e painéis |

## No editor

| Atalho | Faz |
|---|---|
| Ctrl+F | Localizar e substituir |
| Ctrl+W | Fechar a aba da nota |
| Alt+← / Alt+→ | Voltar / avançar entre notas |
| Ctrl+\ | Abrir outra nota ao lado (painel dividido) |
| Ctrl+M | Inserir fórmula |
| Ctrl+Z / Ctrl+Shift+Z | Desfazer / refazer |
| Ctrl+B / Ctrl+I | Negrito / itálico (no modo Visual) |

## No editor de fórmulas

| Atalho | Faz |
|---|---|
| `\` + começo do comando | Sugestões |
| ↑ ↓ e Enter | Escolhe a sugestão |
| Enter | Insere a fórmula |
| Esc | Cancela |
