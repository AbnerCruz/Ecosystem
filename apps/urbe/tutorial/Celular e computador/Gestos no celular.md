# Gestos no celular

O Urbe foi feito primeiro para o celular.

## Na Cidade

| Gesto | Faz |
|---|---|
| Arrastar | Anda pelo mapa |
| Pinça (dois dedos) | Aproxima e afasta |
| Tocar numa casa | Abre o painel da casa |
| Tocar no ＋ | Criar nota, pasta, construção ou importar |

## Na aba Notas

| Gesto | Faz |
|---|---|
| Tocar | Abre a nota ou a pasta |
| Tocar e segurar | Seleciona (depois, toques somam à seleção) |

## No editor

| Gesto | Faz |
|---|---|
| Selecionar texto | Aparece a bolha de formatação |
| `/` numa linha vazia | Menu de tipo de bloco |
| `[[` | Lista de notas para ligar |
| Tocar numa fórmula | Abre o editor de fórmulas |
| Tocar num link de nota | Abre a nota |
| Rolar a barra de ferramentas para o lado | Mostra mais botões |

## Em qualquer lugar

- As janelas que sobem de baixo (menus, diálogos) fecham no **×** ou tocando fora delas.
- O botão **voltar** do topo do editor volta para a Cidade.

Se algum botão não responder ao toque, veja [[Tutorial/Celular e computador/Diagnóstico de toques|Diagnóstico de toques]].
