# O mapa

O botão 🗺️ **Mapa** (no topo da Cidade) abre uma visão do mundo inteiro, como um mapa de papel.

## Como usar

- **Arraste** para explorar outras regiões.
- **Pinça** (ou roda do mouse) para aproximar e afastar. Os botões **＋** e **－** fazem o mesmo.
- **Toque num lugar** para ir até lá na cidade.
- O botão **◎** volta para onde você está.
- O **retângulo** marca a parte do mundo que aparece na sua tela agora.
- O **×** fecha o mapa.

## Cores do mapa

Cada cor é um tipo de terreno: verde para campos e florestas, bege para praias e desertos, cinza para montanhas, branco para neve e azul para água. Os **bairros** aparecem com a cor que você escolheu para cada pasta.
