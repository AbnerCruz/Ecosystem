# Como a cidade funciona

O Urbe desenha as suas notas como uma cidade medieval. Não é só enfeite: o desenho mostra como as suas ideias se organizam.

| No caderno | Na cidade |
|---|---|
| Uma nota | Uma **casa** |
| Uma pasta | Um **bairro** (uma área colorida com nome) |
| Uma pasta dentro de outra | Um bairro dentro de outro bairro |
| Um link `[[Nome da nota]]` | Uma **rua** entre as duas casas |
| Notas ligadas | **Moradores** andando de uma casa para outra |

## O que isso mostra

- **Casas sem rua** são notas soltas: nenhuma outra nota fala delas, e elas não falam de nenhuma. Às vezes é bom ligar essas ideias a outras.
- **Ruas movimentadas** mostram notas centrais, que se conectam a muitas outras.
- **Bairros grandes** são assuntos com muitas notas.

## Tipos de construção

Arquivos diferentes viram construções diferentes:

| Arquivo | Construção |
|---|---|
| Nota `.md` | Casa |
| Página `.html` | Salão |
| Código `.js` | Oficina |
| Estilo `.css` | Tinturaria |
| Dados `.json` / `.yaml` | Torre |
| Tabela `.csv` | Mercado |
| Imagens e outros arquivos | Armazém |

O material das casas também muda com o terreno: no deserto são de barro, na neve têm telhados pesados, e assim por diante.

## O mundo

A cidade fica num mundo grande, gerado a partir do nome da sua cidade: campos, florestas, montanhas, rios, lagos, praias, desertos e neve. O nome do terreno onde você está aparece no topo da tela, ao lado de **Urbe**.
