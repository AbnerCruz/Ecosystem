# Recuperar alterações não salvas

O Lunet salva o arquivo ao sair do editor, executar o jogo ou deixar o aplicativo. Enquanto você digita, ele também guarda um buffer após uma pausa curta, com até cinco versões recentes de cada arquivo. Isso ajuda se o aplicativo for encerrado inesperadamente antes de salvar.

Ao reabrir o projeto depois de uma interrupção, escolha **Recuperar** ou **Descartar** para cada arquivo apresentado. **Última edição não salva** contém o texto mais recente; as outras opções mostram versões anteriores. Ao recuperar, a versão escolhida é gravada no projeto e as cópias temporárias daquele arquivo são removidas. Descartar remove somente as cópias temporárias; o arquivo salvo permanece como estava.

Você também pode abrir **⋯ → Ferramentas → Recuperar alterações não salvas** enquanto houver uma edição aguardando salvamento. Se não existir nenhuma, o Lunet informa isso. Salvar normalmente remove as cópias temporárias; elas não são histórico permanente, nem substituem exportar o projeto em ZIP ou usar Git.
