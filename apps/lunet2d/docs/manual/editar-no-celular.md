# Edite código no celular

Toque no código para abrir seu teclado. Na barra de programação, **Desfazer** e **Refazer** ficam à esquerda. Deslize a barra para encontrar delimitadores, recuo, cursor e busca. **Inserir bloco** envolve a seleção e deixa o cursor na linha interna.

Em chamadas C#, a faixa de assinatura destaca o parâmetro ativo. Toque no contador para alternar sobrecargas. Abra **Todas as ações** e use **Buscar símbolo no projeto** para saltar ao método. Use **Voltar à posição anterior** para retornar ao cursor.

Toque em **Arquivos** e selecione um arquivo para substituir a aba padrão. Pressione o arquivo e escolha **Abrir em nova aba** para deixá-lo aberto além da padrão.
