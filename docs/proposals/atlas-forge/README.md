# Atlas Forge — proveniência da primeira entrega

O proprietário aprovou a incorporação na **DEC-0054 / ADD-0031 / ADR-0035**. A fonte canônica executável passa a ser [apps/atlas-forge](../../../apps/atlas-forge/README.md); não há uma segunda cópia do editor nesta proposta.

Preservados neste diretório: [mandato original](MISSION.md), [auditoria do primeiro incremento](docs/AUDIT.md), [evidências de execução](docs/VERIFICATION.md) e capturas/benchmarks correspondentes. Os caminhos `docs/proposals/atlas-forge/src`, scripts e comandos apresentados nas evidências antigas descrevem o estado efetivamente testado naquela entrega. Os comandos atuais estão no README do aplicativo.

Classificação, independência, stack e limites da incorporação: [arquitetura](../../architecture/atlas-forge.md). Nenhuma release de produção ou validação Android é inferida da mudança de diretório.
