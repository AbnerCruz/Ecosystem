## Pergunta

O mecanismo do ADR-0008 deve ser aceito como está, trocado por clique único com token no navegador, ou rejeitado?

## Alternativas no momento da escolha

A. **Aceitar o ADR-0008: Issue pré-preenchida e confirmação no GitHub (dois toques; nenhum token no navegador)** ← escolhida
   Mesmo fluxo e mesma segurança das decisões: só o dono é aceito, a Issue é a trilha, nenhum segredo no site. A automação só altera o resultado de uma verificação humana pendente, no handoff (fonte única), e o agente continua dono do estado do handoff.

B. **Trocar por clique único: token do GitHub guardado no navegador**
   Um toque só, mas um token de escrita fica em um site público estático (risco de vazamento e XSS), criado e renovado por você, sem confirmação independente. Exigiria novo ADR e nova implementação.

C. **Rejeitar e voltar a validar pelo chat**
   Remove a superfície de escrita para validações; o agente voltaria a editar o handoff com sua palavra no chat.
