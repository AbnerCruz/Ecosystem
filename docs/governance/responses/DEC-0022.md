## Pergunta

Qual tecnologia de UI e plataforma-alvo o Hub inicial deve usar?

## Alternativas no momento da escolha

A. **Android nativo em C# (net10.0-android), a mesma pilha do Lunet2D** ← escolhida
   Reaproveita SDK, build e CI já usados; cumpre o gate no celular; só Android — desktop/iOS exigiriam outra UI depois (a leitura de dados ficaria numa biblioteca independente de UI, então só a camada de UI seria refeita). Recomendação.

B. **UI C# multiplataforma (.NET MAUI ou Avalonia), Android primeiro**
   Abre caminho para desktop (e talvez iOS) com uma base de UI; introduz uma pilha e uma CI novas, e o custo de manter plataformas que o gate não exige.

C. **Web/PWA em C# (Blazor WebAssembly) servida como site estático**
   Abre no celular sem instalar; sobrepõe-se ao portal (que já é a superfície web) e não serve às fases 4–5 (instalar/abrir apps, IPC) sem outra camada nativa.
